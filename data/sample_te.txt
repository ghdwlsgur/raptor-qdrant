* 다른 문자열과 구분된 문자열

# 1 문자와 단어 표현

## 📄 단어 단위 분석 관련 용어

### ➡️ 토큰(Token)

* 분석에 유용한 의미적 단위로 함께 모여지는 일련의 문자열

* 구분 기호 사이의 글자 시퀀스

### ➡️ 타입(Type)

* 중복을 제외한 구별되는(distinct) 문자열

* 같은 단어는 하나로 취급

----

**A** good **wine** is **a** **wine** that you like

Token : 9개, Type : 7개

# 2 구 표현

## 📄 N-gram

* n개의 연속적인 단어들의 나열

* n은 사용한 단어의 개수를 의미

  **n = 1** uni-gram
  
  **n = 2** bi-gram
  
  **n = 3** tri-gram

* 단어의 순서를 통계적으로 모델링하는데 사용

---



# 2 구 표현

## 📋 N-gram 예시

### 주어진 문장

```
The future depends on what we do in the present
```

### uni-gram

```
The, future, depends, on, what, we, do, in, the, present
```

### bi-gram

```
The future, future depends, depends on, …, the present
```

### tri-gram

```
The future depends, future depends on, …, in the present
```

# 2 구 표현

## 📄 텍스트 단위화(Text chunking)

### ➡️ 명사구

* 동사의 주체나 객체가 되는 요소

* 여러 단어로 하나의 개념을 더 명확하게 설명

**예** [주어진 문장] We saw the yellow dog

[ 명사구 ] We, the yellow dog

---



# 2 구 표현

## 📄 텍스트 단위화(Text chunking)

### ➡️ 동사구

• 조동사, 동사 수식어를 포함하는 요소

• 동사는 전치사와 함께 쓰여 여러 의미를 가짐

**예**
• **look at** : ~보다  
  Can you **look at** this photo and tell me what you think?

• **look for** : ~을 찾다  
  I'm going to **look for** my keys.

• **look after** : ~을 돌보다  
  I need someone to **look after** my dog.

## 텍스트 전처리란?

주어진 텍스트에서 노이즈와 같이 불필요한 부분을 제거하고,
문장을 표준 단어들로 분리한 후, 각 단어의 품사를 파악하는 것

1. 정제

2. 정규화

3. 토큰화

4. 정규 표현식

5. 표제어 추출과 어간 추출

6. 품사 태깅

---



# 영어 텍스트 전처리

## 📄 정제(Cleaning)

* 분석의 목적에 맞지 않는 불필요한 노이즈를 제거

▷ 토큰화 이후에도 정제는 지속적으로 이뤄짐

----

**예**
* 저빈도 단어: 100,000개의 문서에 1번 등장하는 단어

* 짧은 단어: 영어의 I, a 등 자연어 처리의 의미가 적은 단어

* 불용어: 정보를 전달하지 않는 단어
  - 영어의 the, a 등의 관사, of, in, to 등의 전치사
  - 웹 스크래핑 결과에 포함된 HTML 태그

※ 불용어는 도메인에 따라 다를 수 있음

---



영어 텍스트 전처리

# 정규화(Normalization)

* 같은 의미를 가진 단어임에도 불구하고 다른 형태로 쓰여진 단어들을 통일시켜 <ins>표준 단어로 변환</ins>

* 고유명사의 기능 등을 고려하여 신중한 처리가 필요

**예**
* 표기가 다른 단어 통일  
  USA → US, uh-huh → uhhuh
* 대소문자 통합  
  Windows → windows

---



# 영어 텍스트 전처리

## 📄 토큰화(Tokenization)

* 주어진 텍스트(문자열)를 원하는 단위(token)로 나누는 작업

* 문장 토큰화와 단어 토큰화로 나뉨

  * 단어보다 더 작은 단위로 토큰화하는 경우도 있음

### ~~토큰화의 고려사항~~

• 구두점이나 특수 문자 : m.p.h, $45.55, 01/02/10

• 축약형과 단어 내 띄어쓰기 : we're, Fred's, New York

• 문장의 경계 : "No pain No gain"

---



# 영어 텍스트 전처리

## 📄 토큰화(Tokenization)

### Penn Treebank Tokenization 예시

```python
from nltk.tokenize import TreebankWordTokenizer

tokenizer = TreebankWordTokenizer()

text = "Starting a home-based restaurant may be an ideal."

print(tokenizer.tokenize(text))
```

> **결과** ['Starting', 'a', 'home-based', 'restaurant', 'may', 'be', 'an', 'ideal.']

---



# 영어 텍스트 전처리

## 📄 정규 표현식(Regular Expression)

○ 문자열에 대해 원하는 **검색 패턴을 지정하는 방법**

○ 문자열을 검색하고 치환하는데 주로 사용됨

### 문자열과 숫자 검색 예시

```python
import re

re.findall('[abc]', 'How are you, boy?')

re.findall('[0123456789]', '3a5b7c9d')
```

**결과**
```
['a', 'b']
['3', '5', '7', '9']
```

---



# 영어 텍스트 전처리

## 정규 표현식(Regular Expression)

### 정규 표현식 예시

```python
from nltk.tokenize import RegexpTokenizer

text = "Mr. Jone's Orphanage is as cheery as cheery goes for a pastry shop"

tokenizer = RegexpTokenizer('[\w]+')
print(tokenizer.tokenize(text))
```

**결과**
['Mr', 'Jone', 's', 'Orphanage', 'is', 'as', 'cheery', 'as', 'cheery', 'goes', 'for', 'a', 'pastry', 'shop']

# 영어 텍스트 전처리

## 표제어 추출과 어간 추출

* 단어의 형태 변화에 따라
  같은 단어라도 다른 단어인 것처럼 취급되는 문제가 있음

  * 같은 형태로 단어를 **일반화**하여 문서 내 단어수를 줄임

  * 빈도수를 기반으로 하는 Bag of Words 방법에 주로 사용

* 여러가지 형태로 표현된 단어들을 **하나의 단어들로 통합**

  * 표제어 추출: 문맥을 고려한 경우에는 단어의 품사 보존

  * 어간 추출: 품사가 보존되지 않고 사전에 없을 수 있음

---



# 영어 텍스트 전처리

## 📄 표제어 추출(Lemmatization)

○ 한 단어가 여러 가지 형식으로 표현되어 있는 것을  
**하나의 단일 형식으로 묶어주는 기법**(Manning and Schutze, 1999)

◉ 표제어(Lemma) : 기본 사전형 단어

◉ 뿌리 단어를 찾아가서 단어의 개수를 줄일 수 있는지 판단

---



# 영어 텍스트 전처리

## 표제어 추출(Lemmatization)

### 1 굴절 형태론(Inflectional morphology)

○ 어기(base)로부터 새로운 어휘의 word-form을 생성

> **예**
> * 영어 동사의 3인칭 단수 굴절 접사 '-s'
> * cutting, cutter ➡ cut

---



# 영어 텍스트 전처리

## 표제어 추출(Lemmatization)

### 2 파생 형태론(Derivational morphology)

○ 어기(base)로부터 새로운 어휘를 생성

**예**
* 영어의 명사화 접미사 '-ion'
* destruction, destructive ➡ destroy

---



# 영어 텍스트 전처리

## 📄 표제어 추출(Lemmatization)

### 표제어 추출 예시

```python
from nltk.stem import WordNetLemmatizer

lemmatizer = WordNetLemmatizer()

words = ['lives', 'fly', 'dies']
print([lemmatizer.lemmatize(word) for word in words])
```

**결과** ['life', 'fly', 'die']

---



# 영어 텍스트 전처리

## 📄 어간 추출(Stemming)

● 어형이 변형된 단어로부터 접사 등을 제거하고  
그 **단어의 어간(stem)을 분리해** 내는 작업

🎯 관련 있는 단어들이 일정하게 동일한 어간으로 매핑

🎯 정해진 규칙만 보고 단어의 어미를 자르는 어림짐작

> **예** **automate**, **automatic**, **automation** ➡ **automat**

---



# 영어 텍스트 전처리

## 포터(Porter) 어간 추출 알고리즘

영어 전처리 과정에서 쓰이는 대표적인 알고리즘

### 규칙

• ATIONAL ➡ ATE     relational ➡ relate
• TIONAL ➡ TION     conditional ➡ condition  
• ENCI ➡ ENCE       valenci ➡ valence
• ANCI ➡ ANCE       hesitanci ➡ hesitance
• IZER ➡ IZE        digitizer ➡ digitize
• ABLI ➡ ABLE       conformabli ➡ conformable
• ALLI ➡ AL         radicalli ➡ radical
• OUSLI ➡ OUS       analogousli ➡ analogous

---



# 영어 텍스트 전처리

## 포터(Porter) 어간 추출 알고리즘

### 포터 알고리즘(Porter Algorithm) 예시

```python
from nltk.stem import PorterStemmer

stemmer = PorterStemmer()

words = ['formalize', 'allowance', 'electrical']
print([stemmer.stem(word) for word in words])
```

**결과** ['formal', 'allow', 'electric']

영어 텍스트 전처리

# 📋 품사 태깅(Part-of-speech(POS) tagging)

* 각각의 단어를 해당하는 품사로 레이블링(labeling)하는 작업
  * 형태소들의 품사와 문장의 구조를 파악

## 품사 태깅 예시

```python
import nltk

words = ['formalize', 'allowance', 'electricical']
print(nltk.pos_tag(words))
```

**결과**
[('formalize', 'VB'), ('allowance', 'NN'), ('electricical', 'JJ')]
